# The Hanging Pass（悬挂工牌）

一个可在浏览器中互动的悬挂式工牌概念展示页：通过拖拽、翻面和材质分层，让一张虚拟工牌的动态与结构细节可被直观看见。

## 页面内容与交互

- **动态悬挂工牌：** 页面以 HTML、CSS 和 JavaScript 绘制工牌、挂绳与扣具，并模拟摆动和回弹。
- **拖动与翻面：** 拖动工牌可改变悬挂角度和绳长；轻点工牌可翻到背面。鼠标移动也会影响卡片倾斜与镭射字样的光泽位置。
- **材质分层视图：** 切换分层模式后，可查看背面印刷、石墨芯、正面印刷、镭射箔和透明膜等图层；点击图层可查看说明，滑杆可调整层间距，按 `Esc` 可收合。
- **展示控制：** 页面提供重新悬挂、自动摆动、镭射高光、回正视角，以及三种挂绳配色选项。
- **响应式缩放：** 窗口尺寸改变时，展示舞台会调整缩放。

页面中的工牌姓名、编号、材质与规格文字属于此概念展示的界面内容；仓库没有提供独立产品数据或外部素材文件。

## 技术实现

- 单页静态网页：`index.html`
- 原生 HTML、CSS 与 JavaScript；样式和脚本内嵌在页面中。
- 仓库没有依赖清单、构建工具配置或外部素材文件。

## 本地预览

无需安装项目依赖或构建。用现代浏览器打开仓库根目录的 `index.html` 即可预览。

## GitHub Pages 部署

仓库包含手动触发的 GitHub Actions 工作流：在仓库的 **Actions** 页面运行 **Deploy to GitHub Pages**，工作流会将 `index.html` 发布到 GitHub Pages。工作流配置为手动触发，不会仅因推送源码而自动发布。
